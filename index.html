تقنيات التشفير والحماية

كل تقنية في صفحة مستقلة: متى نعملها، وظيفتها، وكيف ننفّذها في العمل مع البرنامج الذي نستخدمه.

التشفير وحماية البيانات

  1. 1التخزين الآمن لكلمات المرور(Safe Password Storage)
  2. 2إدارة الحقوق الرقمية(Digital Rights Management - DRM)
  3. 3تشفير الملفات والمجلدات والأقراص(File, Folder and Disc Encryption)
  4. 4التشفير المدمج(Built-in Encryption)
  5. 5الموجّه البصلي(The Onion Router - Tor)
  6. 6الشبكة الخاصة الافتراضية(Virtual Private Network - VPN)
  7. 7الشهادات الرقمية وهيئات التصديق(Digital Certificates and Certificate Authorities - CAs)
  8. 8بروتوكول نقل النص التشعبي الآمن(Hypertext Transfer Protocol Secure - HTTPS)
  9. 9المفتاح العام والمفتاح الخاص(Public Key and Private Key)

حماية الشبكة المحلية اللاسلكية (Wireless Local Area Network - WLAN)

  1. 10تصفية عنوان التحكم بالوصول للوسائط(Media Access Control filtering - MAC filtering)
  2. 11إخفاء معرّف مجموعة الخدمة(Service Set Identifier hiding - SSID hiding)
  3. 12الخصوصية المكافئة للشبكات السلكية(Wired Equivalent Privacy - WEP)
  4. 13الوصول المحمي للواي فاي الجيل الثاني(Wi-Fi Protected Access 2 - WPA2)
  5. 14إعداد الواي فاي المحمي(Wi-Fi Protected Setup - WPS)

طريقة بناء النظام

  1. 15الأمن بالتصميم(Security by Design)
