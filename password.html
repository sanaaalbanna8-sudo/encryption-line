التخزين الآمن لكلمات المرور (Safe Password Storage)

متى نعملها

نعملها عندما نحفظ كلمات مرور المستخدمين داخل نظام أو موقع، حتى تبقى محمية إذا وصلت قاعدة البيانات (Database) إلى شخص غير مصرّح له.

وظيفتها

وظيفتها حماية كلمة المرور من القراءة. نحول الكلمة بالتجزئة (Hashing) إلى بصمة باتجاه واحد، فلا ترجع البصمة إلى الكلمة الأصلية.

نضيف مع البصمة التمليح (Salting)، وهي قيمة مختلفة لكل حساب. التمليح (Salting) يمنع هجوم القاموس (Dictionary Attack) وجداول قوس قزح (Rainbow Tables) من كشف الكلمات المحفوظة دفعة واحدة.

كيف نعملها عملياً

في نظام تسجيل الدخول (Login System) لا نكتب كلمة المرور كما هي داخل قاعدة البيانات (Database). النظام يضيف التمليح (Salting) ثم يحسب التجزئة (Hashing) ويحفظ الناتج. عند تسجيل الدخول يعيد الحساب ويقارن الناتج المحفوظ.

البرنامج الذي نستخدمهنظام الحسابات في الموقع أو قاعدة البيانات (Database). الإعداد يكون داخل النظام عند إنشائه.
  1. نجهّز جدول الحسابات في قاعدة البيانات (Database).
  2. نجعل النظام يضيف التمليح (Salting) لكل حساب.
  3. نحفظ ناتج التجزئة (Hashing)، ولا نحفظ الكلمة نفسها.
  4. عند الدخول نعيد التجزئة (Hashing) ونقارنها بالناتج المحفوظ.
