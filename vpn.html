الشبكة الخاصة الافتراضية (Virtual Private Network - VPN)

متى نعملها

نستخدمها عندما نعمل على شبكة عامة مثل الإنترنت، ونريد خصوصية وإخفاء عنوان بروتوكول الإنترنت (Internet Protocol - IP).

وظيفتها

وظيفتها إنشاء نفق مشفّر بين جهاز المستخدم وخادم الشبكة الخاصة الافتراضية (Virtual Private Network - VPN). مزود الخدمة أو المتلصص لا يقرأ البيانات المارة في هذا النفق.

كيف نعملها عملياً

نفتح تطبيق الشبكة الخاصة الافتراضية (Virtual Private Network - VPN) أو نضيف الاتصال من إعدادات ويندوز (Windows)، ثم نتصل بالخادم.

البرنامج الذي نستخدمهتطبيق الشبكة الخاصة الافتراضية (Virtual Private Network - VPN)، أو إعدادات ويندوز (Windows) ثم الشبكة والإنترنت ثم الشبكة الخاصة الافتراضية (Virtual Private Network - VPN).
  1. نفتح التطبيق أو صفحة الشبكة الخاصة الافتراضية (Virtual Private Network - VPN) في ويندوز (Windows).
  2. نضيف عنوان الخادم إذا لم يكن الاتصال جاهزاً.
  3. نضغط اتصال.
  4. يصير المرور داخل نفق مشفّر بين الجهاز والخادم.
